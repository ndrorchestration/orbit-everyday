# Orbit Everyday — Project Baseline

## Identity

Orbit Everyday is a private, on-device map of where thoughts return.

## User-facing model

1. Today — current thought activity and observations.
2. Patterns — recurring loops and detected structure.
3. Questions — open questions and unexplored topics.

## Analytical layer

The project description calls for mathematical analysis presented through plain language. Named methods are Gram eigenvalues, kNN density, and Lyapunov analysis.

## Constraints

- On-device processing
- Offline operation
- No backend
- Privacy-first handling of user thought data

## Current repository state

This is a preparation baseline. The actual application source from the referenced ZIP was not available in the supplied archive-preview HTML. Missing implementation details are therefore intentionally left open.
